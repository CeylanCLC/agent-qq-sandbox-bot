# 从旧版迁移

## 原则

- 不重装已工作的 NapCat 和 OpenClaw。
- 不删除群记忆、巡群状态、数据库或环境文件。
- 不在生产文件上做不带校验的字符串替换。
- 先在副本上测试，保留一条可直接执行的回滚路径。

## 机器人

旧版只有根目录 `qq_openclaw_bridge.py` 时，把新 `bot/` 目录安装到独立目标并迁移环境变量。根目录兼容启动器仍可使用，但 systemd 推荐直接指向 `bot/qq_openclaw_bridge.py` 所在部署目录。

原先写死在代码里的机器人名称、触发词、域名和群黑名单应迁入 `/etc/qq-openclaw-bot.env`。完成后用搜索确认源码不再含真实值。

## 网站

`website/app.py` 是完整参考实现。已有 Flask 管理后台不得直接覆盖；应复制扩展模块与 HTML/CSS，并在现有 `app.py` 末尾按参考顺序调用各 `install(app, globals())`。保持原管理员 session key、访客数据库和反向代理配置。

## 旧遥测

新版网站会读取旧快照中的黑名单 ID 以过滤历史条目，但不会再持久化或返回这些 ID。部署新版机器人后，下一次遥测会彻底改用 `blocklist_enabled` 与 `blocked_group_count`。

## 验证

迁移后检查普通群、黑名单群、私聊、图片、长期记忆、巡群、心跳、详细遥测、控制操作、API Key 回滚和移动端页面。任何一项失败都先回滚代码，不要删除状态文件。
